02

What has been built so far

The strategy doc covers each item below in full. This recap names them so the current state reads at a glance.

  • Three-phase funnel mapped: audience build (Weeks 1-6), lead capture (Weeks 4-10), conversion (Week 8 onward).
  • Lead angle set: AWS Cost Optimisation as the primary message across all three phases, with security tested underneath it.
  • Audience targeting recipe defined: roughly 80,000 to 120,000 active members across Australia, New Zealand, and Singapore, leaning toward FinOps, platform, and infrastructure leaders plus the engineering managers who answer for the AWS bill.
  • Lead magnets named: "The 2026 AWS Cost Reduction Playbook" as the primary, "AWS Security Posture Checklist" kept ready as the secondary.
  • Kill rules and KPIs set per phase: CPM, cost per follower, video completion, CPL, cost per landing-page submit, and Conversation Ads reply rate, each with a spending limit that triggers a pause.
  • 90-day execution timeline drafted, with phase boundaries that move back by a week or two if the audience build is slower than expected.
  • Tracking plan scoped: LinkedIn Insight Tag to deploy via the existing GTM container GTM-TV9VXWHD, conversion events for follow, video view, lead-gen submit, and landing-page submit.
  • Reporting cadence aligned with the format already running for Google Ads: a weekly Slack post and a one-page HTML report every two weeks.
  • Risks documented: Zoho admin access, Google verification, CPC running above band, Singapore audience size, and the Conversation Ads dependency on Baz's account.

06

Open dependencies and what to watch

  • Zoho admin access pending with Baz. Phase 2 leads route to a holding list weekly until access is in place, then load into the live Zoho flow with the right Lead Source tagging. Phase 3 retargeting needs Zoho live, but Phase 3 does not start until week 8 either way.
  • LinkedIn billing setup. The first campaign cannot launch until a billing method is attached at the campaign account level. Quick check with Baz once Sean is admin on the page.
  • Singapore audience size. Tested in a separate ad set. If Singapore cannot spend its daily cap inside seven days, the ad set pauses and spend returns to Australia and New Zealand.
  • CPC running above band. If CPC sits 30% above the upper band for two consecutive weeks, the targeting needs widening or the creative is wrong. Both responses sit inside the weekly optimisation block.
  • Conversation Ads dependency on Baz's account. Phase 3 Conversation Ads run from a named sender, defaulting to Baz. Replies route wherever Baz wants them to land.
