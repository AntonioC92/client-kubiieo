Google Ads — what was improved

Campaign 1 (Managed Services) is live and has been steadily tuned. The optimisation score is now 81%, ad strength is Good, and the consultation form on /contact is firing as a clean conversion signal so Smart Bidding has real data to work with.

  • Bid strategy refinement. Manual CPC tightened across the active ad groups, with caps adjusted off live impression-share data.
  • Six-sitelink suite added. FinOps audit, managed services, migrations, security, our work, why Kubiieo. The ad now takes more SERP real estate.
  • Service Catalog asset. Structured snippets added so the platforms and services list shows directly in the ad.
  • Negative keyword expansion. 23 new exclusions added based on the live search-terms report. Spend stays on qualified intent.
  • Keyword coverage widened. New phrase variants brought in for managed services, AWS support, and cost optimisation.
  • Ad strength elevated to Good. RSA headlines and descriptions rewritten, pinning relaxed where it was hurting the score.
  • Conversion measurement validated end-to-end. Consultation Request tag firing in GTM, conversion logged in Google Ads (AW-18096994923 / PTQyCIiukKQcEOv0qLVD), event flowing into GA4.
  • Stale duplicate conversion action removed. Old duplicate Consultation action archived so the bidding model only sees the canonical signal.

What I'm picking up next

These are the items I'm executing on directly over the next one to two weeks. Nothing here is blocking the campaign or the page launches on its own, but ticking them off lifts the conversion signal, removes the last polish items on the pages, and gets us ready to scale.

Google Ads

  • Phone-call conversion tracking, going live this week. Updating the WordPress tel: link, flipping click_to_call to a Key Event in GA4, and creating the Phone Call Lead conversion action in Ads. Adds a second clean signal feeding the bidding model.
  • Move to Smart Bidding once we have ~30 conversions banked. Switch from Manual CPC to Maximise Conversions or Target CPA so Google's model can take over the bid decisions on data we trust.
  • Launch Campaigns 2 and 3. Professional Services (35% of budget) and Entry-Point Offers (20%) live alongside Managed Services, on the 45/35/20 split agreed in the strategy doc.
  • First 30-day performance report. Delivered with optimisation recommendations for the next cycle, against a target CPL under $200 AUD on Campaign 1.

WordPress / Landing Pages

  • Real Zoho CRM webhook. Replacing the placeholder action attribute on all three forms with the live Zoho Flow or Deluge endpoint, once Zoho admin access is granted.
  • Six new Zoho custom fields on the Leads module. Three for Page 2 (current environment, workload size, migration trigger), three for Page 3 (engineering team size, compliance frameworks, AWS account count). Pick-lists and multi-select pick-list.
  • Form widget upgrade. Convert the styled HTML forms to the native Elementor Pro Form widget so Email, Redirect and Webhook actions all fire from one place.
  • Thank-you page variants. Single template with conditional copy by querystring (?lp=cost, ?lp=migration, ?lp=devsecops), each with a Calendly or Zoho Bookings embed so high-intent prospects can self-book the read-out call.
  • Theme page-title duplication fix. Toggle the VamTam "Hide page title" option per page so the H1 stops doubling up above the hero.
  • Compliance Frameworks delimiter fix. One-line Zoho Flow string transform so the comma-separated values from Page 3's checkbox set map cleanly into the Zoho multi-select pick-list.
  • Lighthouse audit. Final pre-publish check against the brief targets (performance ≥ 90, accessibility ≥ 95, page weight under 1.5MB), once the forms are converted and the draft banners removed.
