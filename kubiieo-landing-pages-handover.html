01

Summary of requirements

Three lead-magnet landing pages are required for kubiieo.com, each tied to a distinct outbound stream. Every page promises a written deliverable inside a fixed timeframe, given in exchange for a short form. All three pages submit to Zoho CRM via webhook and feed the downstream marketing automation.

Page 1 · Cost

Free AWS Cost Assessment

A 5-page report inside 48 hours showing where the prospect is overspending on AWS. Targets Head of Engineering and CTO, with a CFO secondary angle. Slug: /aws-cost-assessment.

Page 2 · Migration

Cloud Migration Readiness Score

A migration readiness scorecard inside one week. Includes risks, quick wins, cost projection, AWS MAP funding eligibility, phased roadmap. Targets data-centre tenants. Slug: /migration-readiness.

Page 3 · DevSecOps

DevSecOps Maturity Scorecard

A 5-page security scorecard mapping AWS posture to auditor-relevant frameworks. Built using Kubiieo's in-house multi-account scanner. Targets CTO, Head of Engineering, CISO, Compliance leads. Slug: /devsecops-scorecard.

Shared shell

Common build standards

All three pages use the same structure: hero, body bullets, optional explainer block, form, trust block. Brand colours: deep blue #1F3A5F primary, AWS orange #FF9900 for the Cost page accent. Forms route to Zoho CRM Leads with hidden UTM and campaign attribution fields.

Hand-off requirements (per the original brief):

  • Build as new pages on the existing kubiieo.com WordPress site, using a single shared template so styles stay consistent.
  • Form integration writes to Zoho CRM Leads with Lead Source set per page, plus hidden UTM and campaign attribution fields.
  • On submit: webhook to Zoho, internal Slack or email notification, GA4 conversion event, redirect to a per-page thank-you variant with a calendar embed.
  • Mobile-first. Lighthouse target ≥ 90 performance, ≥ 95 accessibility. Page weight under 1.5MB.
  • SEO meta titles and descriptions written for organic and paid quality score.
